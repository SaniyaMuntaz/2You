# Hyperlocal Marketplace

A full-stack hyperlocal service marketplace connecting customers with verified local skilled workers and freelancers in Hyderabad.

## Features
- **Dual Authentication Gateway:** Separate login roles for Customers and Freelancers.
- **Geospatial Worker Search:** Locates local service providers using MongoDB 2dsphere indexing.
- **Category Filtering:** Search across Electricians, Plumbers, Carpenters, Painters, Cleaners, and more.
- **Trust Metrics:** View Google ratings, review counts, trust scores, and portfolio previews.

## Tech Stack
- **Frontend:** React (Vite)
- **Backend:** FastAPI (Python)
- **Database:** MongoDB Atlas (Geospatial Indexing)
- **Hosting:** Render
